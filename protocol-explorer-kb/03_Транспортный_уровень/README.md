# Транспортный уровень (L4)

Как данные доставляются между программами: надёжно (TCP), быстро (UDP) или и то и другое (QUIC).

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [TCP](Протоколы/TCP.md) — Transmission Control Protocol: TCP превращает доставку пакетов «по возможности» в надёжный упорядоченный поток байтов.
- [UDP](Протоколы/UDP.md) — User Datagram Protocol: UDP отправляет данные независимыми пакетами — датаграммами, без соединения, подтверждений и повторов.
- [QUIC / HTTP/3](Протоколы/QUIC_HTTP3.md) — HTTP/3 поверх QUIC: QUIC — новый транспорт поверх UDP со встроенным TLS 1.3.
