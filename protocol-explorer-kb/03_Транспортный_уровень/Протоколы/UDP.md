# UDP
**User Datagram Protocol** · раздел: [Транспортный уровень (L4)](../README.md)

## Суть
UDP отправляет данные независимыми пакетами — датаграммами, без соединения, подтверждений и повторов. Поэтому он быстрый и лёгкий: подходит для голоса, видео, игр и DNS, где опоздавший ответ хуже потерянного.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Транспортный (4) |
| Соединение | Нет |
| Надёжность | Нет (ни ACK, ни повторов) |
| Порядок | Не гарантирован |
| Заголовок | 8 байт |
| Описан в | RFC 768 |

## Как работает (по шагам)
1. Отправить сразу — без рукопожатия
2. Поток датаграмм — каждые 20 мс, каждая сама по себе
3. Потеряна в пути — никто её не повторяет
4. Ответы приходят — голос собеседника
5. Решает приложение — надёжность на совести программы

## Основные термины
- **Датаграмма** — Самостоятельный пакет UDP.
- **Без соединения** — Данные отправляются без предварительной установки связи.
- **Джиттер** — Неравномерность задержки пакетов.
- **Потеря пакетов** — Пакеты, не дошедшие до получателя; UDP их не повторяет.
