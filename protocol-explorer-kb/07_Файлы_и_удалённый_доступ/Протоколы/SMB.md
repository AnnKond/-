# SMB
**Server Message Block (SMB 3)** · раздел: [Файлы и удалённый доступ](../README.md)

## Суть
SMB — способ, которым Windows делится файлами и принтерами: \\server\share в проводнике, подключённый сетевой диск, домашний NAS. macOS и Linux тоже его понимают. Через одно TCP-соединение на порт 445 клиент согласует версию, входит, подключается к общей папке, затем открывает, читает, пишет и закрывает файлы нумерованными запросами.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | TCP 445 |
| Версия | SMB 3.1.1 |
| Вход | NTLM или Kerberos |
| Защита | Подпись, необязательное шифрование |
| Описан в | MS-SMB2 (Microsoft) |

## Как работает (по шагам)
1. Порт 445 — TCP-соединение с NAS
2. Negotiate — согласование версии
3. NTLM-вызов — NAS присылает случайное число
4. NTLM-ответ — доказательство, а не пароль
5. Подключение к папке — \\nas\Documents
6. Открыть файл — CREATE
7. Прочитать — весь файл одним запросом
8. Закрыть файл — и не открывать 445 в интернет

## Основные термины
- **Общая папка (share)** — Папка, доступная по сети.
- **NAS** — Сетевое хранилище.
- **NTLM** — Вход по схеме «вызов — ответ».
- **Kerberos** — Вход через билеты от доменного сервера.
- **Подпись SMB** — Защита сообщений от подмены.
