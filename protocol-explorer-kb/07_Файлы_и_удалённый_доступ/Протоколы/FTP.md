# FTP
**File Transfer Protocol** · раздел: [Файлы и удалённый доступ](../README.md)

## Суть
FTP передаёт файлы между клиентом и сервером. Необычно то, что он использует два TCP-соединения: одно для команд и ответов, а для каждого файла или списка — новое. Протокол родом из начала 1970-х и передаёт всё, включая пароли, открытым текстом.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порты | 21 управление, данные — по-разному |
| Соединения | Управляющее + по одному на передачу |
| Шифрование | Нет (открытый текст) |
| Безопаснее | SFTP или FTPS (FTP + TLS) |
| Описан в | RFC 959 |

## Как работает (по шагам)
1. Управляющее соединение — порт 21, открытый текст
2. Вход — USER и PASS, видны всем
3. Пассивный режим — сервер называет порт для данных
4. Соединение данных — второе TCP-соединение
5. Файл приходит — закрытие соединения означает конец
6. Выход — закрытие управляющего соединения

## Основные термины
- **Управляющее соединение** — Канал для команд (порт 21).
- **Соединение данных** — Отдельный канал для файла.
- **Пассивный режим (PASV)** — Сервер открывает порт, клиент подключается.
- **SFTP** — Передача файлов через SSH.
- **FTPS** — FTP, защищённый TLS.
