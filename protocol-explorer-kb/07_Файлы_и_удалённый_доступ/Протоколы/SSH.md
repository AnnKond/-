# SSH
**Secure Shell** · раздел: [Файлы и удалённый доступ](../README.md)

## Суть
SSH даёт зашифрованное проверенное соединение с другим компьютером: выполнять на нём команды, копировать файлы (SFTP, scp) или пробрасывать другие соединения. Сервер доказывает свою подлинность ключом хоста, пользователь — парой ключей или паролем.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | 22 |
| Транспорт | TCP |
| Сервер доказывает | Ключ хоста (known_hosts) |
| Пользователь доказывает | Пара ключей или пароль |
| Описан в | RFC 4251–4254 |

## Как работает (по шагам)
1. Приветствие — версии открытым текстом
2. Согласование алгоритмов — списки KEXINIT, побеждает первое совпадение
3. Обмен ключами — общие ключи и проверка ключа хоста
4. Вход по ключу — подпись вместо передачи секрета
5. Открыть сеанс — каналы внутри одного соединения
6. Ввод команды — каждая клавиша — отдельный пакет

## Основные термины
- **Ключ хоста** — Ключ, которым сервер подтверждает подлинность.
- **known_hosts** — Файл с запомненными ключами серверов.
- **Пара ключей** — Закрытый (у пользователя) и открытый (на сервере) ключ.
- **Канал (channel)** — Логический поток внутри SSH-соединения.
- **Проброс портов** — Передача других соединений через SSH (ssh -L, -D).
