# Файлы и удалённый доступ

Передача файлов и управление удалёнными компьютерами.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [FTP](Протоколы/FTP.md) — File Transfer Protocol: FTP передаёт файлы между клиентом и сервером.
- [SMB](Протоколы/SMB.md) — Server Message Block (SMB 3): SMB — способ, которым Windows делится файлами и принтерами: \\server\share в проводнике, подключённый сетевой диск, домашний NAS.
- [SSH](Протоколы/SSH.md) — Secure Shell: SSH даёт зашифрованное проверенное соединение с другим компьютером: выполнять на нём команды, копировать файлы (SFTP, scp) или пробрасывать другие соединения.
