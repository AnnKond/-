# База знаний: как работает интернет

Структурированный конспект материалов сайта [Protocol Explorer](https://protocol-explorer-alpha.vercel.app/) — интерактивного справочника по сетевым протоколам.
На сайте разобраны **39 протоколов**: у каждого есть описание, ключевые факты и пошаговая анимация обмена пакетами.

## Как устроен проект
Материал разделён на **тематические папки**. В каждой папке раздела лежат только два элемента:
- `README.md` — обобщающий файл: о чём раздел и краткое содержание каждой заметки;
- одна вложенная папка (`Протоколы/`, в разделе «Основы» — `Темы/`), где лежит по одному текстовому файлу на каждый протокол или тему.

Каждый файл протокола имеет одинаковую структуру:
1. **Суть** — что делает протокол и зачем он нужен.
2. **Ключевые факты** — уровень OSI, порт, транспорт, стандарт (RFC).
3. **Как работает** — шаги обмена, как в анимации на сайте.
4. **Основные термины** — определения ключевых понятий.
5. **Связанные протоколы** — ссылки на другие заметки (связи двусторонние).

Связи между темами показаны тремя способами: ссылками внутри заметок, [картой связей](00_Основы/Темы/Карта_связей.md) и общим [глоссарием](00_Основы/Темы/Глоссарий.md) (210 терминов).

## С чего начать
1. [Модель OSI](00_Основы/Темы/Модель_OSI.md) — как устроены уровни сети.
2. [Что происходит, когда открываешь сайт](00_Основы/Темы/Открытие_сайта_по_шагам.md) — главный сценарий, связывающий DNS, TCP, TLS и HTTP.
3. Далее — любой раздел по интересу.
