# POP3
**Post Office Protocol, версия 3** · раздел: [Электронная почта](../README.md)

## Суть
POP3 позволяет почтовому приложению скачивать письма из ящика на сервере. Он задуман для одного устройства, которое забирает почту и удаляет её с сервера. Команды — короткие слова, каждый ответ начинается с +OK или -ERR.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порты | 995 (TLS), 110 (STLS) |
| Транспорт | TCP |
| Модель | Скачать, затем удалить |
| Ответы | +OK или -ERR |
| Описан в | RFC 1939 |

## Как работает (по шагам)
1. Безопасное подключение — порт 995, TLS с самого начала
2. Вход — USER, затем PASS
3. Проверка ящика — STAT и LIST
4. Скачивание — RETR 1
5. Удаление и выход — удаляется только при QUIT

## Основные термины
- **RETR** — Команда скачивания письма.
- **DELE** — Пометка письма на удаление.
- **+OK / -ERR** — Успешный и ошибочный ответ.
- **Модель «скачать и удалить»** — Письма хранятся на устройстве, а не на сервере.
