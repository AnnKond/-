# SMTP
**Simple Mail Transfer Protocol** · раздел: [Электронная почта](../README.md)

## Суть
SMTP перемещает почту: из почтового приложения на сервер провайдера и с этого сервера на сервер получателя. Это диалог коротких текстовых команд, на каждую сервер отвечает трёхзначным кодом. Чтение почты — другая задача, её решают IMAP и POP3.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порты | 465/587 отправка, 25 пересылка |
| Транспорт | TCP, обычно с TLS |
| Команды | EHLO, MAIL, RCPT, DATA |
| Ответы | 2xx ок, 3xx продолжай, 4/5xx ошибка |
| Описан в | RFC 5321, RFC 6409 |

## Как работает (по шагам)
1. Безопасное подключение — порт 465, TLS с самого начала
2. Приветствие и вход — EHLO, затем AUTH
3. Отправка письма — сначала «конверт», потом содержимое
4. Найти сервер Боба — поиск MX-записи в DNS
5. Сервер — серверу — порт 25 с STARTTLS
6. Доставка — та же процедура ещё раз

## Основные термины
- **Конверт (envelope)** — Адреса отправителя и получателя (MAIL FROM, RCPT TO).
- **EHLO** — Приветствие клиента.
- **DATA** — Команда передачи текста письма.
- **MX-запись** — DNS-запись почтового сервера домена.
- **STARTTLS** — Переход незашифрованного соединения на TLS.
- **Код ответа** — Трёхзначное число: 250 — успех.
