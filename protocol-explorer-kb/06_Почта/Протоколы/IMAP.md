# IMAP
**Internet Message Access Protocol** · раздел: [Электронная почта](../README.md)

## Суть
IMAP позволяет приложениям работать с ящиком, который остаётся на сервере. Папки, отметки «прочитано» и «важное», удаления хранятся там же, поэтому телефон, ноутбук и веб-почта видят один и тот же ящик. Сервер может сам сообщить приложению о новом письме.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порты | 993 (TLS), 143 (STARTTLS) |
| Транспорт | TCP |
| Модель | Почта остаётся на сервере |
| Синхронизирует | Папки и флаги |
| Описан в | RFC 9051, RFC 3501 |

## Как работает (по шагам)
1. Безопасное подключение — порт 993, TLS с самого начала
2. Вход — команды несут метки (теги)
3. Открыть «Входящие» — SELECT папки
4. Прочитать письмо — FETCH и флаг \Seen
5. Ждать новую почту — IDLE: сервер сам присылает

## Основные термины
- **Тег команды** — Метка, связывающая команду и ответ.
- **SELECT** — Выбор папки.
- **FETCH** — Получение письма или его частей.
- **Флаги** — Отметки письма: \Seen, \Flagged, \Deleted.
- **IDLE** — Режим ожидания с мгновенными уведомлениями.
