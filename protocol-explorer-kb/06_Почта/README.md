# Электронная почта

Отправка почты (SMTP) и её получение (POP3, IMAP).

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [SMTP](Протоколы/SMTP.md) — Simple Mail Transfer Protocol: SMTP перемещает почту: из почтового приложения на сервер провайдера и с этого сервера на сервер получателя.
- [POP3](Протоколы/POP3.md) — Post Office Protocol, версия 3: POP3 позволяет почтовому приложению скачивать письма из ящика на сервере.
- [IMAP](Протоколы/IMAP.md) — Internet Message Access Protocol: IMAP позволяет приложениям работать с ящиком, который остаётся на сервере.
