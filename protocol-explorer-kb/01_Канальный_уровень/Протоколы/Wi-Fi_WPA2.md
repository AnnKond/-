# Wi-Fi (WPA2)
**Wi-Fi 802.11 с защитой WPA2** · раздел: [Канальный уровень (L2)](../README.md)

## Суть
Wi-Fi передаёт сеть по радио. Прежде чем отправить данные, устройство должно найти сеть, подключиться к ней и доказать, что знает пароль. В WPA2-Personal таким доказательством служит четырёхстороннее рукопожатие: четыре коротких сообщения превращают пароль в свежие ключи шифрования, а сам пароль по воздуху не передаётся.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Канальный (2) |
| Стандарт | IEEE 802.11 |
| Защита | WPA2: CCMP (AES) |
| Подключение | Probe, аутентификация, ассоциация |
| Ключи | Из 4-стороннего рукопожатия |
| Описан в | IEEE 802.11-2020 |

## Как работает (по шагам)
1. Найти сеть — маяк (beacon), затем запрос probe
2. Подключиться — две формальности: аутентификация и ассоциация
3. Сообщения 1 и 2 — обмен случайными числами (nonce)
4. Сообщения 3 и 4 — установка ключей
5. Шифрование включено — и что ещё может сделать подслушивающий

## Основные термины
- **SSID** — Имя беспроводной сети.
- **Маяк (beacon)** — Кадр, которым точка доступа объявляет о своей сети.
- **Ассоциация** — Регистрация устройства на точке доступа.
- **4-стороннее рукопожатие** — Обмен 4 сообщениями для получения ключей из пароля.
- **Nonce** — Случайное одноразовое число для свежести ключей.
- **CCMP / AES** — Алгоритм шифрования кадров в WPA2.
- **Точка доступа (AP)** — Устройство, создающее Wi-Fi сеть.
