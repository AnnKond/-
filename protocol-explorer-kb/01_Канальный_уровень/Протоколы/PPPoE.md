# PPPoE
**Point-to-Point Protocol over Ethernet** · раздел: [Канальный уровень (L2)](../README.md)

## Суть
Многие DSL- и оптические провайдеры требуют, чтобы домашний роутер «вошёл» перед выходом в интернет. PPPoE позволяет это: роутер находит сервер доступа провайдера, открывает с ним сеанс, внутри запускает PPP — согласует параметры канала, входит по логину и паролю от провайдера и получает публичный IP-адрес. Затем каждый пакет несёт 8-байтовый заголовок PPPoE.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Канальный (2) |
| Обнаружение | PADI, PADO, PADR, PADS |
| Вход | CHAP или PAP |
| Адрес | Через IPCP |
| Накладные расходы | 8 байт (MTU 1492) |
| Описан в | RFC 2516, RFC 1661 |

## Как работает (по шагам)
1. Есть кто-нибудь? — роутер ищет сервер доступа (PADI)
2. Выбрать сервер — номер сеанса для линии
3. Параметры канала — LCP согласует размер и способ входа
4. Вход — проверка пароля без передачи пароля (CHAP)
5. Получить адрес — IPCP выдаёт публичный IP
6. В сети — каждый пакет в 8-байтовой обёртке

## Основные термины
- **PPP** — Протокол связи «точка — точка» с входом и настройкой адреса.
- **PADI/PADO/PADR/PADS** — Четыре сообщения фазы обнаружения PPPoE.
- **LCP** — Протокол настройки параметров канала PPP.
- **CHAP** — Вход по схеме «вызов — ответ» без передачи пароля.
- **IPCP** — Протокол выдачи IP-адреса в PPP.
- **MTU** — Максимальный размер пакета; у PPPoE — 1492 байта.
