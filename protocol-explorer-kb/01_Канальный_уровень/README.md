# Канальный уровень (L2)

Как данные передаются внутри одной локальной сети: по кабелю, по радио, через провайдера.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [Ethernet](Протоколы/Ethernet.md) — Ethernet и коммутаторы: Ethernet — основа почти всех проводных сетей; точки доступа Wi-Fi тоже передают трафик в Ethernet.
- [Wi-Fi (WPA2)](Протоколы/Wi-Fi_WPA2.md) — Wi-Fi 802.11 с защитой WPA2: Wi-Fi передаёт сеть по радио.
- [PPPoE](Протоколы/PPPoE.md) — Point-to-Point Protocol over Ethernet: Многие DSL- и оптические провайдеры требуют, чтобы домашний роутер «вошёл» перед выходом в интернет.
