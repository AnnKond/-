# Modbus
**Modbus/TCP для промышленного управления** · раздел: [Промышленные сети (OT)](../README.md)

## Суть
Modbus — один из старейших и самых распространённых протоколов промышленного управления (OT, операционные технологии): на нём говорят ПЛК, датчики, приводы и счётчики на заводах, водоканалах и в зданиях. Клиент читает и записывает нумерованные регистры и катушки (coils) устройства. Modbus/TCP переносит те же короткие сообщения через TCP-порт 502 — без входа и без шифрования.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | TCP 502 |
| С | 1979 года, Modicon |
| Данные | 16-битные регистры, катушки вкл/выкл |
| Безопасность | Встроенной нет |
| Описан в | Спецификации Modbus.org |

## Как работает (по шагам)
1. Порт 502 — TCP-соединение с ПЛК
2. Чтение регистров — функция 3: четыре числа
3. Запись уставки — функция 6: один регистр
4. Запуск насоса — функция 5: катушка
5. Исключение — нет такого регистра
6. Нет защиты — любой, кто может подключиться

## Основные термины
- **OT** — Операционные технологии — управление физическим оборудованием.
- **ПЛК (PLC)** — Программируемый логический контроллер.
- **Регистр** — 16-битная ячейка данных устройства.
- **Катушка (coil)** — Однобитный выход «вкл/выкл».
- **Код функции** — Номер операции: 3 — чтение, 6 — запись регистра, 5 — запись катушки.
- **Уставка** — Заданное значение параметра (например, температуры).
