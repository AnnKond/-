# Промышленные сети (OT)

Протоколы управления оборудованием на заводах и в инфраструктуре.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [Modbus](Протоколы/Modbus.md) — Modbus/TCP для промышленного управления: Modbus — один из старейших и самых распространённых протоколов промышленного управления (OT, операционные технологии): на нём говорят ПЛК, датчики, приводы и счётчики на заводах, водоканалах и в зданиях.
