# HTTP-прокси
**Прямой прокси и CONNECT для HTTPS** · раздел: [Прокси и VPN](../README.md)

## Суть
Прямой прокси загружает страницы за вас. Компании и школы используют его, чтобы фильтровать сайты, хранить копии популярных страниц и журналировать трафик; сайты видят прокси, а не вас. Обычный HTTP проходит через него открыто. Для HTTPS браузер просит у прокси туннель (CONNECT), и зашифрованное соединение идёт через него непрочитанным.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Типичные порты | 8080, 3128 |
| http:// страницы | Загружаются прокси |
| https:// страницы | Туннелируются через CONNECT |
| Применение | Фильтрация, кэш, журналы |
| Описан в | RFC 9110 (CONNECT: §9.3.6) |

## Как работает (по шагам)
1. Настройки прокси — браузер отправляет всё туда
2. К прокси — TCP на порт 8080
3. Полный URL — GET http://www.example.com/
4. Прокси загружает — своё соединение с сервером
5. Страница передана — клиенту
6. HTTPS: CONNECT — CONNECT www.example.com:443
7. В туннеле — прокси копирует, не читая

## Основные термины
- **Прямой (forward) прокси** — Посредник на стороне клиента.
- **CONNECT** — HTTP-метод создания туннеля.
- **Туннель** — Канал, через который данные идут без изменения.
- **Кэширование** — Хранение копий страниц.
- **Фильтрация контента** — Блокировка нежелательных сайтов.
