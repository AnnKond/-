# WireGuard
**Современный VPN** · раздел: [Прокси и VPN](../README.md)

## Суть
VPN передаёт трафик внутри зашифрованного туннеля до VPN-сервера, а тот отправляет его в интернет. В Wi-Fi кафе другие видят только зашифрованные пакеты к VPN-серверу, а сайты — адрес VPN-сервера вместо вашего. WireGuard — современный VPN: мало кода, один фиксированный набор современных алгоритмов и рукопожатие из двух сообщений.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Сетевой (3) |
| Транспорт | UDP (по умолчанию 51820) |
| Рукопожатие | 2 сообщения, 1 RTT |
| Криптография | Curve25519, ChaCha20-Poly1305 |
| Идентификация | Открытые ключи, как в SSH |
| Описан в | Документ WireGuard (whitepaper) |

## Как работает (по шагам)
1. Настройка один раз — ключи, а не пароли
2. Рукопожатие — два сообщения, один круговой обмен
3. В туннель — пакет внутри пакета
4. В интернет — расшифрован и отправлен дальше
5. Обратный путь — снова запечатан для ноутбука
6. Поддержание — keepalive и новые ключи

## Основные термины
- **VPN** — Виртуальная частная сеть — зашифрованный туннель.
- **Туннелирование** — Вложение пакета внутрь другого пакета.
- **Пир (peer)** — Участник WireGuard-соединения.
- **Curve25519** — Алгоритм обмена ключами.
- **ChaCha20-Poly1305** — Алгоритм шифрования с проверкой целостности.
