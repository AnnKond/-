# NTP
**Network Time Protocol** · раздел: [Сетевые сервисы](../README.md)

## Суть
Часы компьютеров уходят на секунды за неделю, а от них многое зависит: у сертификатов есть даты, входы и платежи истекают, журналы разных машин должны совпадать. NTP устанавливает часы по серверу времени. Один маленький запрос и ответ несут четыре метки времени — достаточно, чтобы вычислить, насколько отстают часы и сколько заняла сеть.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | UDP 123 |
| Сообщение | 48 байт |
| Метки времени | 4: T1–T4 |
| Точность | Несколько миллисекунд |
| Описан в | RFC 5905 |

## Как работает (по шагам)
1. Часы уходят — часы ноутбука немного отстают
2. Запрос времени — T1: когда ушёл запрос
3. Ответ — T2 и T3 от сервера, T4 при получении
4. Смещение — четыре времени, два ответа
5. Плавная подстройка — без скачков назад

## Основные термины
- **Смещение (offset)** — Насколько локальные часы отличаются от точного времени.
- **Задержка (delay)** — Время прохождения запроса по сети.
- **T1–T4** — Метки времени отправки/приёма у клиента и сервера.
- **Stratum** — Уровень удалённости сервера от эталонных часов.
