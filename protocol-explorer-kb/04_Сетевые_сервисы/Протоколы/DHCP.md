# DHCP
**Dynamic Host Configuration Protocol** · раздел: [Сетевые сервисы](../README.md)

## Суть
DHCP выдаёт устройству всё, что нужно для работы в сети: IP-адрес, маску подсети, маршрутизатор (шлюз) и DNS-серверы. Адреса выдаются в аренду на срок и продлеваются, пока устройство остаётся в сети.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порты | UDP 67 (сервер), 68 (клиент) |
| Выдаёт | IP, маску, шлюз, DNS |
| Обмен | Discover, Offer, Request, Ack |
| Аренда | Продлевается на половине срока |
| Описан в | RFC 2131, RFC 2132 |

## Как работает (по шагам)
1. Нет адреса — ноутбук подключается к сети
2. Discover — крик на всю сеть
3. Offer — роутер предлагает адрес
4. Request — принять, вслух
5. Acknowledge — адрес закреплён за ноутбуком
6. Renew — продление на половине аренды

## Основные термины
- **DORA** — Discover, Offer, Request, Acknowledge — четыре шага получения адреса.
- **Аренда (lease)** — Срок, на который выдан адрес.
- **Шлюз по умолчанию** — Маршрутизатор для выхода из сети.
- **DHCP-сервер** — Обычно встроен в домашний роутер.
