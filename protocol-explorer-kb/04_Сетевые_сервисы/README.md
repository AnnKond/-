# Сетевые сервисы

Служебные протоколы, которые незаметно делают сеть удобной: имена, автоматические настройки, точное время.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [DNS](Протоколы/DNS.md) — Domain Name System: DNS превращает имена вроде www.example.com в IP-адреса, по которым компьютеры находят друг друга.
- [DHCP](Протоколы/DHCP.md) — Dynamic Host Configuration Protocol: DHCP выдаёт устройству всё, что нужно для работы в сети: IP-адрес, маску подсети, маршрутизатор (шлюз) и DNS-серверы.
- [NTP](Протоколы/NTP.md) — Network Time Protocol: Часы компьютеров уходят на секунды за неделю, а от них многое зависит: у сертификатов есть даты, входы и платежи истекают, журналы разных машин должны совпадать.
