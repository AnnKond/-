# Веб

Протоколы, на которых работают сайты и веб-приложения.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [HTTP](Протоколы/HTTP.md) — Hypertext Transfer Protocol: HTTP — протокол веба: клиент запрашивает ресурс, например HTML-страницу, а сервер отвечает кодом состояния, заголовками и обычно телом.
- [HTTPS](Протоколы/HTTPS.md) — HTTP Secure: HTTPS — это HTTP внутри зашифрованного TLS-соединения.
- [WebSocket](Протоколы/WebSocket.md) — Протокол WebSocket: WebSocket держит одно открытое соединение между страницей и сервером, так что любая сторона может отправить сообщение в любой момент: чаты, спортивные счета, игры, совместные документы.
