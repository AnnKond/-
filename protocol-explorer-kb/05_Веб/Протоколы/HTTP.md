# HTTP
**Hypertext Transfer Protocol** · раздел: [Веб](../README.md)

## Суть
HTTP — протокол веба: клиент запрашивает ресурс, например HTML-страницу, а сервер отвечает кодом состояния, заголовками и обычно телом. Каждый обмен — это один запрос и один ответ, записанные читаемым текстом в HTTP/1.1.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | 80 (HTTPS: 443) |
| Транспорт | TCP |
| Формат | Текст (заголовки + необязательное тело) |
| Методы | GET, POST, PUT, DELETE, HEAD |
| Описан в | RFC 9110, RFC 9112 |

## Как работает (по шагам)
1. Запрос клиента — браузер готовит запрос
2. Разрешение DNS — поиск IP-адреса сервера
3. TCP-соединение — установка надёжной связи
4. Обмен HTTP — сообщения запроса и ответа
5. Отрисовка страницы — браузер показывает содержимое

## Основные термины
- **Запрос / ответ** — Основная единица обмена HTTP.
- **Метод** — Действие: GET — получить, POST — отправить, PUT — заменить, DELETE — удалить.
- **Код состояния** — 200 OK, 301 перенаправление, 404 не найдено, 500 ошибка сервера.
- **Заголовки** — Служебные поля: Host, Content-Type и др.
- **Тело (body)** — Содержимое: HTML, JSON, изображение.
- **URL** — Адрес ресурса: схема, хост, путь.
