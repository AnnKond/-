# HTTPS
**HTTP Secure** · раздел: [Веб](../README.md)

## Суть
HTTPS — это HTTP внутри зашифрованного TLS-соединения. TLS доказывает сертификатом, что сервер тот, за кого себя выдаёт, согласует свежие ключи и защищает каждый запрос и ответ от чтения и изменения по пути.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (HTTP поверх TLS) |
| Порт | 443 |
| Транспорт | TCP |
| Защита | TLS 1.3 (часто 1.2) |
| Доказывает | Подлинность сервера (сертификат) |
| Описан в | RFC 9110, RFC 8446 |

## Как работает (по шагам)
1. Защищённый запрос — браузер просит https://
2. Поиск DNS — как у HTTP, не зашифрован
3. TCP-рукопожатие — соединение с портом 443
4. TLS-рукопожатие — ключи и проверка сертификата
5. Зашифрованный обмен — HTTP внутри TLS-записей
6. Отрисовка — браузер показывает замок

## Основные термины
- **Сертификат** — Документ, подтверждающий, что ключ принадлежит домену.
- **Центр сертификации (CA)** — Организация, подписывающая сертификаты.
- **Замок в браузере** — Признак защищённого соединения.
- **TLS-запись** — Зашифрованный блок данных.
