# Сетевой уровень (L3)

Адресация устройств и доставка пакетов из сети в сеть.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [IP](Протоколы/IP.md) — Internet Protocol: IP даёт каждому устройству адрес и переносит пакеты из сети в сеть.
- [IPv6](Протоколы/IPv6.md) — IPv6: SLAAC и обнаружение соседей: Адреса IPv6 имеют длину 128 бит — хватит каждому устройству.
- [ICMP](Протоколы/ICMP.md) — Internet Control Message Protocol: ICMP — это способ сети сообщать о проблемах: маршрутизатор говорит, что время пакета истекло, сервер — что на порту никто не слушает.
- [IGMP](Протоколы/IGMP.md) — Internet Group Management Protocol: Групповая рассылка (multicast) отправляет один поток на групповой адрес, а сеть копирует его только туда, где он нужен — так провайдеры доставляют телеканалы IPTV.
- [BGP](Протоколы/BGP.md) — Border Gateway Protocol: Интернет — сеть сетей: десятки тысяч сетей провайдеров, облаков, университетов и компаний, у каждой свой номер AS.
