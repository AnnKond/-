# IGMP
**Internet Group Management Protocol** · раздел: [Сетевой уровень (L3)](../README.md)

## Суть
Групповая рассылка (multicast) отправляет один поток на групповой адрес, а сеть копирует его только туда, где он нужен — так провайдеры доставляют телеканалы IPTV. IGMP — способ, которым устройство сообщает маршрутизатору, какие группы ему нужны. Коммутаторы подслушивают эти сообщения (IGMP snooping), и поток идёт только на запросившие порты.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Сетевой (3) |
| Передаётся в | IP (протокол 2) |
| Группы | 224.0.0.0 – 239.255.255.255 |
| Сообщения | Report, Query, Leave |
| Версия | IGMPv2 |
| Описан в | RFC 2236 (v3: RFC 3376) |

## Как работает (по шагам)
1. Выбор канала — ТВ-приставка вступает в группу
2. Запрос к провайдеру — роутер вступает за весь дом
3. Канал идёт — только туда, где его просили
4. Второй экран — ноутбук тоже подключается
5. Ещё смотрите? — роутер регулярно опрашивает
6. Выход — ноутбук перестаёт смотреть

## Основные термины
- **Multicast** — Доставка одного потока группе получателей.
- **Групповой адрес** — IP-адрес из диапазона 224.0.0.0/4.
- **Membership Report** — Сообщение «хочу получать группу».
- **IGMP snooping** — Подслушивание IGMP коммутатором для адресной рассылки.
- **IPTV** — Телевидение по IP-сети.
