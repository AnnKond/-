# IPv6
**IPv6: SLAAC и обнаружение соседей** · раздел: [Сетевой уровень (L3)](../README.md)

## Суть
Адреса IPv6 имеют длину 128 бит — хватит каждому устройству. Устройство обычно настраивается само, без DHCP: создаёт локальный адрес канала, спрашивает маршрутизатор и строит глобальный адрес из объявленного префикса (SLAAC). Обнаружение соседей (часть ICMPv6) находит MAC-адреса — то, что в IPv4 делает ARP.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Сетевой (3) |
| Адрес | 128 бит |
| Автонастройка | SLAAC, без сервера |
| Вместо ARP | Neighbour Discovery |
| DHCPv6 | Необязателен |
| Описан в | RFC 8200, 4861, 4862 |

## Как работает (по шагам)
1. Сначала link-local — адрес создаётся самим ноутбуком
2. Есть маршрутизаторы? — Router Solicitation
3. Ответ роутера — префикс, MTU и DNS одним сообщением
4. Глобальный адрес — префикс + идентификатор интерфейса
5. Поиск соседа — кто владеет адресом (работа ARP)
6. Готово — без DHCP и без NAT

## Основные термины
- **SLAAC** — Автоматическая настройка адреса без сервера.
- **Link-local адрес** — Адрес fe80::…, работающий только в своей сети.
- **Префикс** — Первая часть адреса, общая для сети.
- **Router Solicitation / Advertisement** — Запрос маршрутизатора и его объявление.
- **Neighbour Discovery** — Механизм ICMPv6 для поиска соседей и их MAC.
- **ICMPv6** — Служебные сообщения для IPv6.
