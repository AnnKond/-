# ICMP
**Internet Control Message Protocol** · раздел: [Сетевой уровень (L3)](../README.md)

## Суть
ICMP — это способ сети сообщать о проблемах: маршрутизатор говорит, что время пакета истекло, сервер — что на порту никто не слушает. На этих сообщениях построены утилиты ping и traceroute. ICMP передаётся внутри IP, но не несёт данных приложений.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Сетевой (3) |
| Передаётся в | IP (протокол 1) |
| Сообщения | Тип и код |
| Утилиты | ping, tracert / traceroute |
| Часто | Фильтруется брандмауэрами |
| Описан в | RFC 792 (IPv6: RFC 4443) |

## Как работает (по шагам)
1. Ping — эхо-запрос
2. Эхо-ответ — измерение времени туда-обратно
3. TTL 1 — отвечает первый маршрутизатор
4. TTL 2 — отвечает следующий
5. Это traceroute — TTL 1, 2, 3 … до цели
6. Недоступно — на порту никто не слушает

## Основные термины
- **ping** — Утилита проверки доступности: Echo Request / Echo Reply.
- **traceroute / tracert** — Утилита, показывающая путь пакета через увеличение TTL.
- **Time Exceeded** — Сообщение «время жизни истекло».
- **Destination Unreachable** — Сообщение «адресат недоступен».
- **Тип и код** — Поля, определяющие вид ICMP-сообщения.
