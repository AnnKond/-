# BGP
**Border Gateway Protocol** · раздел: [Сетевой уровень (L3)](../README.md)

## Суть
Интернет — сеть сетей: десятки тысяч сетей провайдеров, облаков, университетов и компаний, у каждой свой номер AS. BGP — способ, которым их пограничные маршрутизаторы сообщают друг другу, какие адреса они могут достичь. Каждый передаёт узнанное дальше, добавляя свой номер, и так каждая сеть строит свою карту путей ко всем адресам. (На сайте BGP отнесён к прикладному уровню, так как работает поверх TCP, но по смыслу это маршрутизация.)

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7), поверх TCP |
| Порт | TCP 179 |
| Между | Сетями (AS) |
| Таблица | Около миллиона маршрутов IPv4 |
| Выбор пути | Политика, затем кратчайший |
| Описан в | RFC 4271 |

## Как работает (по шагам)
1. Много сетей — у каждой свой номер
2. Открыть сеанс — TCP на порт 179
3. Приветствие — OPEN, затем KEEPALIVE
4. Объявить маршрут — сеть хостинга: «у меня эти адреса»
5. Передано дальше — каждая сеть добавляет свой номер
6. Следование маршруту — пакеты идут, куда сказал BGP
7. Отзыв — маршруты можно забрать обратно
8. Проблемы доверия — BGP верит соседям

## Основные термины
- **AS (автономная система)** — Сеть одной организации с единой политикой маршрутизации.
- **ASN** — Номер автономной системы.
- **Пиринг** — Сеанс BGP между двумя сетями.
- **AS_PATH** — Список сетей, через которые прошло объявление.
- **UPDATE / Withdraw** — Объявление и отзыв маршрутов.
- **Угон маршрута (hijack)** — Ложное объявление чужих адресов.
