# IP
**Internet Protocol** · раздел: [Сетевой уровень (L3)](../README.md)

## Суть
IP даёт каждому устройству адрес и переносит пакеты из сети в сеть. Каждый маршрутизатор смотрит только на адрес назначения и выбирает следующий переход. IP работает «по возможности» (best effort): не обещает ни доставки, ни порядка — это добавляет TCP поверх.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Сетевой (3) |
| Адрес | 32 бита (IPv4), 128 (IPv6) |
| Заголовок | 20–60 байт (IPv4) |
| TTL | Уменьшается на 1 на каждом маршрутизаторе |
| Доставка | Best effort |
| Описан в | RFC 791, RFC 8200 (IPv6) |

## Как работает (по шагам)
1. Своя сеть или нет? — адрес сравнивается с подсетью
2. Найти маршрутизатор — ARP превращает IP в MAC
3. Отправить пакет — адреса, TTL и протокол
4. NAT, затем переход за переходом — роутер переписывает адрес и пересылает
5. Ответ возвращается — NAT переводит его обратно для ноутбука

## Основные термины
- **IP-адрес** — Числовой адрес устройства в сети.
- **Подсеть / маска** — Диапазон адресов одной локальной сети.
- **TTL** — «Время жизни» пакета: число переходов, после которых пакет уничтожается.
- **Маршрутизация** — Выбор следующего перехода по адресу назначения.
- **NAT** — Замена частного адреса публичным на роутере.
- **Best effort** — Доставка без гарантий.
