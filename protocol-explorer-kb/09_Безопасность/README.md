# Безопасность

Шифрование, проверка подлинности и защита от подмены.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [TLS/SSL](Протоколы/TLS.md) — Transport Layer Security: TLS создаёт защищённый канал поверх TCP.
- [DNS over HTTPS](Протоколы/DNS_over_HTTPS.md) — DNS-запросы внутри HTTPS: Обычный DNS передаётся открыто: любой в той же Wi-Fi сети и провайдер видят каждое имя, которое вы ищете, и даже могут подменить ответ.
- [DNSSEC](Протоколы/DNSSEC.md) — DNS Security Extensions: Обычные DNS-ответы можно подделать: кто ответил первым или стоит посередине, может прислать ложный адрес.
- [WPA3](Протоколы/WPA3.md) — Wi-Fi Protected Access 3: WPA3 — актуальный стандарт защиты Wi-Fi.
- [RADIUS / 802.1X](Протоколы/RADIUS_802.1X.md) — RADIUS и 802.1X (корпоративный Wi-Fi): Дома все используют один пароль Wi-Fi.
