# RADIUS / 802.1X
**RADIUS и 802.1X (корпоративный Wi-Fi)** · раздел: [Безопасность](../README.md)

## Суть
Дома все используют один пароль Wi-Fi. Офисы, университеты и eduroam используют WPA2/WPA3-Enterprise: каждый человек или устройство входит со своей учётной записью или сертификатом, которые проверяет RADIUS-сервер. Точка доступа паролей не знает — она передаёт вход (серию EAP-сообщений) между ноутбуком и сервером и пускает ноутбук, только когда сервер скажет «да».

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Канальный (2) |
| Стандарт | IEEE 802.1X |
| Вход | EAP (здесь EAP-TLS) |
| Проверяет | RADIUS, UDP 1812 |
| Ключи | Свои для каждого входа |
| Описан в | RFC 2865, 3579, 5216 |

## Как работает (по шагам)
1. Кто вы? — точка доступа запрашивает идентификатор
2. Спросить RADIUS — вход уходит на сервер
3. TLS внутри EAP — сервер доказывает, кто он
4. Доказательство ноутбука — его собственный сертификат
5. Рукопожатие завершено — больше нечего отправлять
6. Access-Accept — и ключ для точки доступа
7. 4-стороннее рукопожатие — как дома, но из другого ключа
8. Почему Enterprise — одна учётная запись на человека

## Основные термины
- **802.1X** — Стандарт контроля доступа к сети по портам.
- **EAP** — Расширяемый протокол аутентификации.
- **EAP-TLS** — Вход по сертификатам.
- **RADIUS-сервер** — Сервер, проверяющий учётные данные.
- **Access-Accept / Access-Reject** — Решение сервера: пустить или нет.
- **eduroam** — Международная Wi-Fi сеть университетов.
