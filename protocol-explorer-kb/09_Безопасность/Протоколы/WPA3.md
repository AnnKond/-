# WPA3
**Wi-Fi Protected Access 3** · раздел: [Безопасность](../README.md)

## Суть
WPA3 — актуальный стандарт защиты Wi-Fi. В режиме Personal остаётся общий пароль, но меняется способ его проверки: SAE — обмен, который нельзя атаковать перебором по записанному трафику — даёт каждому подключению свежий ключ. Также обязательны защищённые служебные кадры.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Канальный (2) |
| Проверка пароля | SAE (Dragonfly) |
| Затем | 4-стороннее рукопожатие |
| Обязательно | Защищённые служебные кадры (PMF) |
| С | 2018 года |
| Описан в | IEEE 802.11-2020, RFC 7664 |

## Как работает (по шагам)
1. Сеть WPA3 — маяк требует SAE
2. SAE Commit — каждая сторона «фиксирует» пароль
3. SAE Confirm — доказательство без пароля
4. Подключение и рукопожатие — далее как в WPA2
5. Почему безопаснее — поддельные отключения больше не работают

## Основные термины
- **SAE** — Безопасный обмен на основе пароля (Dragonfly).
- **Атака перебором офлайн** — Подбор пароля по записанному рукопожатию; WPA3 её исключает.
- **PMF** — Защищённые служебные кадры.
- **Атака деаутентификации** — Поддельное отключение клиента; PMF её блокирует.
- **Forward secrecy** — Старый трафик нельзя расшифровать, даже узнав пароль позже.
