# Голос и видео

Звонки, видеосвязь, камеры и прямые трансляции.

Все материалы раздела лежат во вложенной папке **`Протоколы/`**.

## Содержание
- [WebRTC](Протоколы/WebRTC.md) — Web Real-Time Communication: WebRTC позволяет двум браузерам созваниваться: звук, видео и данные идут напрямую между ними, а не через сервер.
- [SIP](Протоколы/SIP.md) — Session Initiation Protocol: SIP устанавливает телефонные звонки через интернет: офисные IP-телефоны, приложения-звонилки и провайдеры за ними.
- [RTSP](Протоколы/RTSP.md) — Real Time Streaming Protocol: RTSP — способ, которым плееры, видеорегистраторы и приложения безопасности получают живое видео с IP-камер.
- [RTMP](Протоколы/RTMP.md) — Real-Time Messaging Protocol: RTMP — способ, которым большинство стримеров отправляют живое видео на платформу: OBS и другие программы передают его на ingest-сервер, который превращает его в потоки для зрителей.
