# SIP
**Session Initiation Protocol** · раздел: [Голос и видео](../README.md)

## Суть
SIP устанавливает телефонные звонки через интернет: офисные IP-телефоны, приложения-звонилки и провайдеры за ними. Телефон регистрируется на SIP-сервере провайдера. Чтобы позвонить, он отправляет INVITE; другой телефон звонит и отвечает, стороны договариваются о передаче голоса, который затем идёт как RTP. Сообщения — простой текст, похожий на HTTP.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | UDP или TCP 5060 |
| Установка звонка | INVITE, 180, 200, ACK |
| Голос | RTP, описанный SDP |
| Кодек | G.711, 64 кбит/с |
| Описан в | RFC 3261 |

## Как работает (по шагам)
1. Регистрация — телефон сообщает серверу, где он
2. Позвонить Бобу — INVITE через сервер
3. Звонит — ответ 180 Ringing идёт обратно
4. Ответили — 200 OK, затем ACK
5. Разговор — голос идёт как RTP
6. Положить трубку — BYE и 200 OK

## Основные термины
- **REGISTER** — Регистрация телефона на сервере.
- **INVITE** — Приглашение к звонку.
- **180 Ringing / 200 OK** — Ответы «звонит» и «ответили».
- **RTP** — Протокол передачи голоса и видео в реальном времени.
- **Кодек** — Способ сжатия звука/видео (G.711, H.264).
- **VoIP** — Голосовая связь по IP.
