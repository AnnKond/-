# RTMP
**Real-Time Messaging Protocol** · раздел: [Голос и видео](../README.md)

## Суть
RTMP — способ, которым большинство стримеров отправляют живое видео на платформу: OBS и другие программы передают его на ingest-сервер, который превращает его в потоки для зрителей. Созданный для Flash, протокол пережил Flash как способ загрузки. Всё идёт по одному TCP-соединению: команды, звук и видео, нарезанные на чанки.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | TCP 1935 |
| Несёт | Видео H.264, звук AAC |
| Команды | Кодируются в AMF0 |
| Защищённая версия | RTMPS (поверх TLS) |
| Описан в | Спецификация Adobe (2012) |

## Как работает (по шагам)
1. Рукопожатие — TCP, затем собственное RTMP
2. Подключение — к приложению live на сервере
3. Создать поток — createStream возвращает поток 1
4. Публикация — ключ трансляции выходит в эфир
5. Видео и звук — метаданные, настройки, затем кадры
6. Остановить трансляцию — FCUnpublish и deleteStream

## Основные термины
- **Ingest-сервер** — Сервер платформы, принимающий трансляцию.
- **Ключ трансляции (stream key)** — Секрет, определяющий, чей это эфир.
- **Чанк** — Кусок сообщения RTMP.
- **AMF0** — Формат кодирования команд.
- **OBS** — Популярная программа для стриминга.
