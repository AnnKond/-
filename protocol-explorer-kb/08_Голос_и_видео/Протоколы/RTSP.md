# RTSP
**Real Time Streaming Protocol** · раздел: [Голос и видео](../README.md)

## Суть
RTSP — способ, которым плееры, видеорегистраторы и приложения безопасности получают живое видео с IP-камер. Он работает как пульт: плеер спрашивает, что умеет камера, настраивает поток, говорит PLAY, а потом TEARDOWN — текстовыми сообщениями, похожими на HTTP. Само видео идёт не в RTSP, а отдельно, как RTP по UDP.

## Ключевые факты
| Параметр | Значение |
|----------|----------|
| Уровень | Прикладной (7) |
| Порт | TCP 554 |
| Команды | SETUP, PLAY, TEARDOWN |
| Видео | RTP, описанный SDP |
| Кодек | H.264 |
| Описан в | RFC 2326 (2.0: RFC 7826) |

## Как работает (по шагам)
1. Что ты умеешь? — OPTIONS по TCP
2. Описать поток — SDP сообщает, какое видео
3. Настройка — согласование портов (SETUP)
4. Воспроизведение — кнопка PLAY
5. Видео приходит — ключевой кадр в RTP-пакетах
6. Стоп — TEARDOWN завершает сеанс

## Основные термины
- **DESCRIBE** — Запрос описания потока.
- **SETUP / PLAY / TEARDOWN** — Настроить, начать, завершить поток.
- **Ключевой кадр (I-frame)** — Полный кадр, от которого строятся следующие.
- **H.264** — Распространённый видеокодек.
- **IP-камера** — Камера, передающая видео по сети.
