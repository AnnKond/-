# Что происходит, когда открываешь сайт

Главный сценарий сайта Protocol Explorer — путь запроса от браузера до страницы. Он связывает сразу несколько разделов базы.

1. **Запрос клиента** — браузер разбирает адрес и готовит запрос.
2. **Разрешение DNS** — по имени www.example.com находится IP-адрес сервера. → [DNS](../../04_Сетевые_сервисы/Протоколы/DNS.md)
3. **TCP-соединение** — тройное рукопожатие SYN → SYN-ACK → ACK. → [TCP](../../03_Транспортный_уровень/Протоколы/TCP.md)
4. **(Для HTTPS) TLS-рукопожатие** — проверка сертификата и согласование ключей. → [TLS](../../09_Безопасность/Протоколы/TLS.md)
5. **Обмен HTTP** — запрос `GET / HTTP/1.1`, ответ `200 OK` с HTML. → [HTTP](../../05_Веб/Протоколы/HTTP.md)
6. **Отрисовка страницы** — браузер показывает содержимое.

## Пример из «Потока пакетов» на сайте
| № | Время | Источник | Назначение | Протокол | Инфо |
|---|-------|----------|------------|----------|------|
| 1 | 0.000 | 192.168.1.10 | 8.8.8.8 | DNS | Standard query A www.example.com |
| 2 | 0.012 | 8.8.8.8 | 192.168.1.10 | DNS | response A 203.0.113.10 |
| 3 | 0.024 | 192.168.1.10 | 203.0.113.10 | TCP | [SYN] |
| 4 | 0.041 | 203.0.113.10 | 192.168.1.10 | TCP | [SYN, ACK] |
| 5 | 0.058 | 192.168.1.10 | 203.0.113.10 | TCP | [ACK] |
| 6 | 0.058 | 192.168.1.10 | 203.0.113.10 | HTTP | GET / HTTP/1.1 |
| 7 | 0.076 | 203.0.113.10 | 192.168.1.10 | HTTP | HTTP/1.1 200 OK (text/html) |

Под капотом также работают [IP](../../02_Сетевой_уровень/Протоколы/IP.md) (доставка пакетов), [Ethernet](../../01_Канальный_уровень/Протоколы/Ethernet.md) или [Wi-Fi](../../01_Канальный_уровень/Протоколы/Wi-Fi_WPA2.md) (передача в локальной сети) и, возможно, [DHCP](../../04_Сетевые_сервисы/Протоколы/DHCP.md) (адрес ноутбуку выдали заранее).
