# Устройства сети

На схеме сайта (вкладка «Сеть») показаны типичные участники сети. Это помогает понять, «кто с кем» общается в каждом протоколе.

| Устройство | Роль |
|------------|------|
| Клиент (ноутбук) | Отправляет запросы |
| Маршрутизатор (роутер) | Соединяет домашнюю сеть с интернетом, делает NAT, раздаёт адреса по DHCP |
| Коммутатор (switch) | Передаёт кадры внутри локальной сети по MAC-адресам |
| DNS-резолвер (8.8.8.8) | Ищет IP-адреса по именам |
| Корневой, TLD и авторитетный DNS-серверы | Уровни иерархии DNS |
| Веб-сервер | Отдаёт страницы сайтов |
| Сервер приложения | Работает за обратным прокси |
| Почтовый сервер | Принимает и хранит почту |
| Файловый сервер / NAS | Хранит общие файлы (SMB, FTP) |
| Прокси | Посредник между клиентом и интернетом |
| Сервер доступа провайдера | Принимает вход по PPPoE |
| Маршрутизаторы провайдера, транзитные, хостинга (AS) | Обмениваются маршрутами по BGP |
| IP-камера | Отдаёт видео по RTSP |
| ТВ-приставка | Принимает IPTV через IGMP |

## Основные термины
- **Маршрутизатор** — устройство, пересылающее пакеты между сетями (уровень 3).
- **Коммутатор** — устройство, пересылающее кадры внутри сети (уровень 2).
- **Резолвер** — сервер, выполняющий DNS-поиск по просьбе клиента.
- **AS (автономная система)** — сеть одной организации со своим номером.
