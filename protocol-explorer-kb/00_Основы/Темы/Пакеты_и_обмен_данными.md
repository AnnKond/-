# Пакеты и обмен данными

Данные в сети передаются не сплошным потоком, а порциями. На сайте в нижней панели «Поток пакетов» видно каждую порцию: время, источник, назначение, протокол и размер — как в анализаторе трафика Wireshark.

## Как называются порции на разных уровнях
| Уровень | Название |
|---------|----------|
| Канальный | Кадр (frame) |
| Сетевой | Пакет (packet) |
| Транспортный | Сегмент (TCP) / датаграмма (UDP) |
| Прикладной | Сообщение (message) |

## Модели обмена
- **Клиент — сервер**: клиент спрашивает, сервер отвечает (HTTP, DNS, SMTP).
- **Точка — точка (peer-to-peer)**: устройства обмениваются напрямую ([WebRTC](../../08_Голос_и_видео/Протоколы/WebRTC.md)).
- **Публикация / подписка, групповая рассылка**: один поток многим получателям ([IGMP](../../02_Сетевой_уровень/Протоколы/IGMP.md)).

## Основные термины
- **Пакет** — единица данных сетевого уровня с адресами отправителя и получателя.
- **Рукопожатие (handshake)** — обмен служебными сообщениями перед передачей данных (TCP, TLS, Wi-Fi).
- **RTT (время кругового пути)** — время, за которое запрос доходит и возвращается ответ.
- **Широковещание (broadcast)** — сообщение всем устройствам локальной сети.
- **Групповая рассылка (multicast)** — сообщение группе подписанных устройств.
- **RFC** — открытый документ-стандарт интернета; в каждой заметке указан RFC протокола.
